# Titanic Data Analysis

## Overview
This project analyzes the Titanic dataset to understand survival patterns.

## Key Steps
- Data Cleaning
- Data Visualization
- Feature Engineering

## Tools Used
- Python
- Pandas
- Seaborn
- Matplotlib

## Insights
- Females had higher survival rates  
- Higher class passengers survived more  
- Fare positively influenced survival  
- Family size impacted survival chances
